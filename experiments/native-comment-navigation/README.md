# Comment Link Probe

> **Архив прежнего проекта Common Structurizer.** Не является действующим решением Personal Notes & Tasks; проверка перехода к комментариям не доказывает работу личных заметок.

Изолированный диагностический плагин этапа 1. Основной продукт и его интерфейс не реализует. Файл Figma не изменяет, комментарии не создаёт и не закрывает, к REST API не обращается.

Ссылка вводится через стандартные параметры запуска Figma, без собственного окна. Прототип передаёт исходный скопированный URL в `figma.openExternal` и завершается. Сообщение о передаче ссылки не означает подтверждение раскрытия ветки.

## Проверки и сборка

```powershell
pnpm test:probe
pnpm probe:comment:build
```

Ссылки в автоматических тестах вымышленные; сеть и браузер этими тестами не открываются. Эти тесты проверяют только сохранение URL и отклонение неподходящих адресов.

## Реальный запуск в Figma

1. Получить собственный ID через стандартное создание локального плагина в Figma. Не использовать ID чужого плагина. Для пилота отдельная регистрация уже создана в `work/figma-comment-probe-registration`.
2. Собрать стенд: `pnpm probe:comment:build --registration work/figma-comment-probe-registration/manifest.json`.
3. Для повторения на этой машине скопировать собранные `dist/code.js` и `dist/manifest.json` в папку регистрации `work/figma-comment-probe-registration`: Figma уже подключена к ней. Либо импортировать собранный манифест через Development. Не подключать одновременно два пути с одним ID.
4. Запустить Comment Link Probe через быстрые действия Figma и вставить исходную ссылку из меню комментария.
5. Проверить, раскрылась ли нужная нативная ветка. Figma может обработать переход внутри приложения. Записать фактический результат в протокол эксперимента.

Параметр `--registration` позволяет использовать отдельную регистрацию эксперимента. Без него ID читается из корневого манифеста продукта. Без ID сборка создаёт только `dist/manifest.template.json`: этот шаблон не считается готовым импортируемым плагином. Корневой манифест сборщик не изменяет.

## Фактический результат 11 ноября 2026 года

Стенд запущен как локальный Development-плагин в установленной Figma Desktop 126.11.8. После ввода исходной ссылки и выбора команды открытия раскрылась нужная нативная ветка. В этой конфигурации Figma обработала URL внутри приложения. Закрытые обсуждения, ответы и ссылки, собранные из REST-данных, этим испытанием не проверены.

Полный протокол: `../../docs/experiments/01-native-comment-navigation.md`.
