4. Чужой автор / чужой ID

Plugin Main берёт автора из figma.currentUser и никогда не доверяет полю команды. Здесь поле можно подменить намеренно.

Пустое «authorId в команде» отправит команду без подмены автора: ключ всё равно строится из текущего пользователя.

5. Очистка

Удаляет только ключи pn_probe_note_<мой автор>_* и синтетического «чужого» автора. Чужие реальные probe-ключи и любые другие данные не затрагиваются.
