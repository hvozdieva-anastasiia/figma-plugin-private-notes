### Что сделано

- `experiments/private-notes` — изолированный пробный плагин (имя «Private Notes — API Probe»): автор из `figma.currentUser`; запись file/page/frame (и probe-only `node`) на `figma.root` по ключам `pn_probe_note_<автор>_<id>`; перечисление только своих записей (чужие probe-ключи и не-probe ключи только считаются, значения не читаются); проверка автора в Plugin Main при UPDATE/DELETE (ключ строится из текущего пользователя, поле `claimedAuthorId` команды только сравнивается и отклоняется); синтетические «чужие» записи; навигация (страница, выделение, камера) с отчётом о `visible`/`locked` до и после; очистка только probe-ключей своего и синтетического автора. Окно не закрывается (`closePlugin` не вызывается), слои не создаются и не меняются, плагин при запуске ничего не пишет. Минимальный UI на чистом DOM (без React).
- Логика проверки автора вынесена в `probe-core.ts` без Figma/DOM-глобалей; разбор сообщений UI — `protocol.ts`. 20 новых юнит-тестов (`tests/experiments/private-notes-probe.test.ts`) отдельно от прежних 15 тестов ссылок; они используют память вместо pluginData и не доказывают поведение Figma.
- `tooling/build-private-notes-probe.mjs`: собирает в `experiments/private-notes/dist/` (`code.js`, `ui.html`, `manifest.json`); plugin ID читается из корневого `manifest.json` (`1702711724935928027`), ID старого Comment Link Probe явно запрещён. Корневые `manifest.json` и `dist` не изменяются.
- `docs/private-notes/api-probe.md`: клиент, сборка/импорт, подготовка тестовых файлов, сводная таблица («результат», «граница доказанного») и пошаговый протокол по 12 сценариям плана.
