## 2. Модель приватности — как реализовано в коде

- **Автор всегда берётся из `figma.currentUser.id`** в Plugin Main
  (`src/plugin/current-user.ts`). Ни одна команда от UI не несёт поля автора;
  `parseCommand` отбрасывает неизвестные поля (`src/shared/messages.ts:452`).
- **Ключи изолированы по автору**: `private_notes_note_<encodedAuthorId>_<id>`
  на `figma.root` (`src/plugin/storage/document-notes.ts:50-61`). Листинг
  читает только ключи текущего автора; чужие ключи только считаются
  (`listOwnNotes`, строки 93–99). Двойная проверка: префикс ключа + поле
  `authorId` внутри записи (строки 125–131).
- **UI не может попросить чужое**: `readOwnNote` строит ключ из текущего
  автора — чужой id даёт только `NOT_FOUND` (строки 163–190).
- **Валидация всего входа**: `parseCommand` проверяет версию протокола, типы,
  id-шаблоны, длину запроса, лимиты пачки (bulk ≤ 500, target-refs ≤ 25).
- **Лимиты продукта** (`src/shared/model.ts`): 4000 символов, 500 записей,
  80 кБ на значение — против переполнения pluginData.
- **В UI нет логирования**: единственный `console.*` в бандле — внутренности
  React (dev-tools hooks), текстов заметок там нет. `navigator` используется
  только для clipboard (`src/ui/clipboard.ts`).
- **Нет мутаций документа**, кроме собственных pluginData-ключей: ни слоёв,
  ни комментариев, ни переименований (подтверждено чтением `figma/*.ts` —
  только чтение узлов, `setCurrentPageAsync`, `selection`,
  `scrollAndZoomIntoView`).

## 3. Сеть и данные

- Ноль сетевых вызовов в `src/` (grep: fetch/XHR/WebSocket/beacon — пусто).
- `clientStorage` хранит только `private-notes:window-size` и
  `private-notes:prefs` (scope списка) — `src/plugin/index.ts:20-63`.
- Clipboard API — единственное «внешнее» действие UI, только по явной кнопке
  «Copy as Markdown», с фолбэком на ручное копирование.

## 5. Потенциальные причины отклонения — чек-лист

По правилам Figma Community для плагинов:

- [x] **Плагин работает, нет заглушек** — все функции реализованы, 374+ тестов, ручной протокол пройден.
- [x] **Нет deceptive/placeholder контента** — описание соответствует коду.
- [x] **Не дублирует core-фичи Figma** — нативные комментарии публичны и командны; приватные per-user заметки — отдельная ниша, дублированием не считается.
- [x] **Сеть задекларирована честно** — `allowedDomains: ["none"]` и реально ноль сети.
- [x] **Нет скрытых платежей/внешних аккаунтов** — их нет вообще.
- [x] **Нет рекламы/подозрительного кода** — нет телеметрии, обфускации, динамической загрузки кода (`eval`, remote scripts — отсутствуют).
- [ ] **Privacy policy URL** — текст готов (`privacy-policy.md`); нужен публичный URL (Gist/репозиторий) — действие пользователя.
- [ ] **Проверка имени на занятость** — поиск в Community перед публикацией.
- [ ] **Скриншоты/иконка/обложка** — готовы в `assets/`; загрузить в форму.
- [ ] **Профиль автора в Community** — должен существовать до публикации (avatar, обложка профиля, ссылки).

## 6. Сборка и проверки

- `pnpm check` = typecheck (TS 7 strict) + eslint + prettier + vitest + build +
  probe build. Статус на момент аудита: **exit 0**, 15 тестовых файлов,
  374/374 теста, `dist/` собран (index.html 275 КБ gzip 84 КБ).
- `dist/` в .gitignore — сборка воспроизводится из исходников; для публикации
  важно, чтобы `dist/` был свежим (`pnpm build` перед Import plugin).
- Секретов в репозитории нет (grep по ключам/токенам/паролям — пусто).
- `.npmrc`: `save-exact=true`, `strict-peer-dependencies=true` — версии
  закреплены, supply-chain гигиена соблюдена.
