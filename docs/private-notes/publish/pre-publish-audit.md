# Personal Notes & Tasks — аудит перед публикацией

Дата: 2026-11-20. Проверены исходники, manifest, настройки сборки, тесты и
локальная production-сборка. Базовая ревизия: `2adb4c8`; изменения этой сессии
касаются документации, материалов публикации и текста пустого экрана UI:
вместо обещания «Only you can see it» прямо указано хранение без шифрования.
Алгоритмы хранения и авторизации не менялись. Плагин на ревью не отправлен.

## Вывод

В проверенном коде не обнаружены отправка заметок наружу, аналитика, скрытые
сетевые обращения, запись чужого автора или вставка текста заметок как HTML.
Это результат чтения кода и автотестов, а не гарантия отсутствия уязвимостей.
Заметки не зашифрованы; фильтрация по автору не обеспечивает секретность данных
Figma-файла. Формулировки листинга и обложки исправлены с учётом этого.

Материалы подготовлены. Перед отправкой нужно обновить публичную policy,
пройти форму и получить отдельное подтверждение отправки. Проверка двух
аккаунтов и клиентов рекомендована для качества основной функции; это не
отдельное формальное условие Figma. Отсутствие шифрования само по себе не
обозначено как причина автоматического отказа: текущее хранение можно оставить
для первого выпуска с честным описанием его границ.

## Сеть и UI

`tests/private-notes/audit.test.ts` проверяет отсутствие сетевых API, console
в исходниках, опасной HTML-вставки, private Figma API, создания/изменения слоёв.
Текст показывается средствами React, без интерпретации HTML/Markdown.
В production UI включён код React; его внутренние диагностические строки
не следует путать с логированием заметок разработчиком.

`clientStorage` содержит размер окна и scope списка, а не базу заметок.
Clipboard используется по явной кнопке; при отказе есть ручное копирование.
Навигация меняет страницу, выделение и viewport, но не создаёт контент холста.
Сохранение pluginData является изменением документа: фраза «nothing is created
in the document» заменена более точной «no comments or canvas layers».

## Границы безопасности

1. **Незашифрованный документ.** `pluginData` изолирован по plugin ID для API
   плагинов, а не по Figma-пользователю на уровне хранения. Чужой plugin ID не
   может читать эти ключи обычным `getPluginData`. Но экспорт или авторизованный
   REST-доступ к файлу могут открыть данные. Это соответствует предупреждению
   [Figma](https://developers.figma.com/docs/plugins/api/properties/nodes-setplugindata/)
   и параметру `plugin_data` в [REST API](https://developers.figma.com/docs/rest-api/file-endpoints/).
2. **Figma sync.** No network относится к самому плагину. Файл и pluginData
   синхронизируются Figma, поэтому «ничего не покидает устройство» неверно.
3. **Удаление не является secure erase.** Удаляется текущий ключ; Undo, история,
   экспорт, резервные и отдельные копии файла могут сохранять прежние записи.
4. **Конкурентные изменения.** Проверка revision работает с локально видимым
   состоянием. Между двумя клиентами нет атомарного compare-and-set и глобальной
   блокировки. Две правки до синхронизации могут столкнуться. Не обещать
   «nothing gets lost» или «never overwrites silently» для всех случаев.
5. **Канал UI.** `figmaTransport` использует parent.postMessage и принимает
   сообщения с `pluginMessage` без проверки `event.source` и полного runtime
   schema ответов. Есть protocol/run/request проверки для responses; context
   события проверяются слабее. В изолированном iframe эксплуатация не доказана.
   Это кандидат на отдельное укрепление, а не установленная утечка или
   доказанный blocker Figma. Канал обмена в этой сессии не менялся.

## Сопоставление с ревью Figma

[Правила Figma](https://help.figma.com/hc/en-us/articles/360039958914-Plugin-and-widget-review-guidelines)
требуют работающий продукт, точные описание и превью, понятную помощь,
поддержку, корректные права и обработку данных. Решение принимает Figma;
категоричного вывода «одобрение гарантировано» или «дублированием не считается» нет.

| Риск                       | Оценка и действие                                                                                                                                                     |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обещание секретности       | Существенный риск вводящего в заблуждение листинга. Убраны «for your eyes only», «only you can read» и гарантии отсутствия потерь; явное not encrypted                |
| Публичная policy устарела  | Подтверждена редакция 2026-11-13 в публичном GitHub. Локальная исправлена; перед отправкой разместить новую                                                           |
| Два аккаунта и два клиента | 20 ноября разделение двух реальных аккаунтов проверено в одном Desktop: каждый видит только свою запись. Два независимых клиента не проверены; это отдельный сценарий |
| Браузер и macOS            | Прогоны 12 и 20 ноября — Windows/Figma Desktop; другие платформы и браузерный клиент не подтверждены                                                                  |
| Новизна и имя              | Ниша личных заметок отличается от командных комментариев, но Figma вправе оценить иначе. Имя не объявляется эксклюзивным; повторить поиск                             |
| Target picker              | Предлагает только top-level frames страницы; вложенный фрейм выбирается до создания на холсте. Уточнено в how-to                                                      |
| Медиа                      | Реальный собранный React UI с fixture-данными, не live-сессия Desktop; происхождение описано. Не использовать как доказательство работы API                           |
| Контакт                    | Публичный issue tracker указан; не просить секреты в публичных issues. Проверить доступность без входа                                                                |
| Права/тема                 | currentuser обоснован; Figma theme variables используются. Финальный Desktop-прогон после подготовки медиа остаётся в checklist                                       |
