## Рекомендуемая ручная проверка перед отправкой

Это внутренний контроль качества, а не отдельное требование Figma о двух
аккаунтах или двух клиентах. Без прогона остаётся непроверенный риск;
шифрование не добавляется автоматически ради прохождения ревью.

Использовать отдельный тестовый Figma-файл с вымышленным текстом. Не удалять
пользовательские записи и не прикладывать их к публичным материалам.

- [x] Основной development-плагин запущен в Desktop со свежей сборкой; probe не использовался.
- [ ] Create/edit/status/delete, file/page/frame, вложенный frame, поиск,
      фильтры, Current selection, переход, потерянная цель и Rebind работают.
- [ ] Bulk и Markdown copy/fallback проверены; закрытие редактора не теряет
      важный текст без понятного предупреждения.
- [ ] Resize и светлая/тёмная тема проверены на текущем клиенте.
- [x] Два реальных аккаунта в одном файле: A видит свою заметку, B её не видит;
      B создаёт и выполняет свою задачу; при возврате A его заметка сохранена,
      задача B не показана. Проверено последовательно в одном Desktop 20 ноября.
- [ ] Дополнительно: повторное открытие B после работы A, остальные CRUD-сценарии
      обоих аккаунтов и независимая синхронизация между устройствами.
- [ ] Один аккаунт в двух клиентах: последовательные изменения, stale draft,
      удаление и Undo проверены; одновременное редактирование описано честно.
- [ ] Браузерный клиент проверен отдельно от Desktop; подтверждены заявленные
      платформы. Старый Windows-протокол не выдаётся за эту проверку.

## Форма Figma Desktop

Официальный путь: Figma logo → Plugins → Manage plugins → меню нужного
development plugin → Publish. См.
[инструкцию Figma](https://help.figma.com/hc/en-us/articles/360042293394-Publish-classic-plugins-to-the-Figma-Community).

- [ ] У автора есть Community profile и включена 2FA.
- [ ] Выбрана публикация в Community и правильный автор/команда; установлена цена
      (предлагается Free) и разрешение комментариев.
- [ ] Вставлены тексты из `listing-texts.md`, без русских служебных пояснений.
- [ ] Загружены `icon-128.png`, `cover.png` 1920×1080 и `slide-1..5.png`;
      проверены порядок, кадрирование и читаемость в превью формы.
- [ ] Указаны актуальные privacy policy, how-to и support contact.
- [ ] Network access отображается как No access to network.
- [ ] При заполнении optional security disclosure ответы сопоставлены с точным
      вопросом; не заявлены encryption, audits или certifications, которых нет.
- [ ] Владелец проверил условия Figma, права на материалы и сведения об авторе.
- [ ] Форма сохранена как конкретный результат для финального просмотра, если
      интерфейс поддерживает сохранение без отправки.
- [ ] Получено отдельное явное подтверждение на нажатие Publish/отправку.
- [ ] После подтверждения выполнена отправка; статус и дата записаны отдельно.

Наличие списка не означает, что какие-либо незаполненные пункты уже выполнены.
