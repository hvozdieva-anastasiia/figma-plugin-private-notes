# Personal Notes & Tasks — поддержка

Английский текст для публичной справки. Issue tracker публичный; подтверждённых
email, private-report канала или SLA в проекте нет, поэтому они не обещаются.

## Public help text

```markdown
Need help with Personal Notes & Tasks?

Report a problem or request a feature:
https://github.com/hvozdieva-anastasiia/figma-plugin-private-notes/issues

Include your Figma client (desktop or browser), operating system, what you
expected, what happened, and steps to reproduce with harmless example text.
For a visual issue, include the theme and plugin window size if possible.

GitHub issues are public. Remove note contents, personal information,
credentials, and private file links from reports and screenshots. For a
sensitive inquiry, ask for a private contact method before sharing details.

Notes missing? Check that you are in the original file and using the same
Figma account. Clear search, choose All and All notes, expand groups, and
refresh. Look in No available target if a page or frame was deleted.

Cannot save? Confirm edit access, a valid target, and the 4,000-character /
500-record limits. If the target was deleted, choose a replacement explicitly.
Copy important unsaved text before closing the plugin or reloading Figma.

Conflict? Compare your draft with the stored record before continuing. The
plugin has no independent backup service or guaranteed cross-client locking.

Cannot copy Markdown? Use the manual-copy text shown by the plugin when
clipboard access is refused.

Deleted something? Figma Undo or version history may help, but Undo may
revert several plugin changes at once. Refresh to see the actual document
state. There is no separate developer database from which notes can be restored.

Uninstalling will not delete saved notes. To remove your current records,
use Select, choose All / All notes with no search, select records, and confirm
Delete. This does not erase Figma history, backups, exports, or file copies.
```
