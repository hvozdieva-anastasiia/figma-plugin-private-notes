## Результат проверки

`pnpm check` прошёл: 374 теста, типы, линтер, форматирование и сборка.
Разрешение только `currentuser`, сеть запрещена, база — `pluginData` на
`figma.root`, автор проверяется в Plugin Main. ID не менялся.

Отсутствие шифрования не обозначено как автоматическая причина отказа Figma.
Для первого выпуска можно оставить текущее хранение с честным описанием его
границ. Плагин показывает записи автора, но не является сейфом для секретов;
Figma синхронизирует данные, а история/копии могут сохранять удалённое.
Revision выявляет видимые устаревшие правки, без гарантии атомарности между
клиентами. Материалы не обещают полной секретности и отсутствия потерь.

## Происхождение изображений

UI не нарисован заново и не сгенерирован моделью. Это настоящий production
`dist/index.html`, отрендеренный локально в Edge с демонстрационной заменой
Plugin Main. Сценарии открывают реальные панели приложения. Имена целей и
тексты записей вымышленные; данные пользователя не использовались.

Рамка окна и холст в слайдах — оформление. Изображения не являются снимками
живого Figma Desktop или доказательством пройденного multi-user теста.
Иконка — SVG в существующем стиле проекта с отметкой задачи. Оформление
использует системный Segoe UI, без скачиваемых шрифтов/CDN.

Для повторного рендера на Windows с Edge:

```powershell
pnpm build
node tooling/publish/render-assets.mjs
```

При другом пути Edge задать `PN_EDGE_PATH`. Генераторы сохранены в
`tooling/publish/`, временные HTML — в игнорируемом `work/publish/`.
Они не входят в плагин и не меняют запрет сети в manifest.

## До отправки

Публичный GitHub-репозиторий и обновлённая policy (редакция 2026-11-20)
опубликованы в main; ссылки проверены без входа.

20 ноября в отдельном файле Starter проверены два реальных аккаунта: B не
видит заметку A, создаёт свою задачу и отмечает её выполненной; после возврата
A видит свою сохранённую запись и не видит задачу B. Функциональной ошибки
в этих сценариях не обнаружено. В пустом экране уточнён текст о хранении без
шифрования. Протокол — [manual-checks.md](../manual-checks.md).

Два независимых клиента и браузер пока не проверены. Это рекомендуемый контроль
качества, а не отдельное формальное требование Figma. Все пункты и условия
формы собраны в чеклисте. Платные места и тарифы для проверки не менялись.

Перед отправкой проверить ссылки без входа, профиль/2FA, цену и превью формы.
Publish отправляет плагин на ревью; нажимать только после отдельного явного
подтверждения пользователя.
